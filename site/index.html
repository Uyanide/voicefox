01 / Features

一个播放器，完整的音乐工作流。

稳定的 TUI 发布线持续打磨，同时保留 Flutter + Rust 的新架构实验线。

多音源聚合

跨音源搜索、失败换源、歌手 / 专辑、歌单、分类与排行榜。

libmpv 播放

ReplayGain、EQ、A-B 循环、淡入淡出与键盘 / 鼠标队列管理。

歌词体验

LRC / KRC / QRC / YRC，支持翻译、罗马音与全屏歌词。

本地音乐库

扫描、标签、封面、歌词、CUE 分轨与文件诊断。

下载与整理

并发分片、完整性校验，以及标签、封面、LRC 写入。

桌面集成

Linux D-Bus / MPRIS、Windows SMTC 媒体键与桌面通知，以及 Kitty / Sixel / iTerm2 封面。

02 / What's New

0.5.0 新增了什么。

从系统音频频谱到睡眠定时器，再到跨端歌单推送与只读镜像缓存。

频谱可视化

按 w 在内容区叠加 cava 风格的柱状频谱，采集系统输出监视流；采集断流会自动重连，不再冻结在最后一帧。

睡眠定时器

按 t 选择 15–120 分钟，到点在最长 10 秒内淡出并暂停；启用后底栏显示倒计时。

Windows SMTC

硬件媒体键、系统媒体浮层与蓝牙耳机按键可控制播放，浮层同步显示封面与歌名。

歌单互通与推送

导入 M3U / M3U8 / LX / 网易云 JSON、导出 M3U8，并把自建歌单或收藏追加推送到网易云。

缓存管理

设置页一键清除封面缓存与网易云歌单镜像，值列显示当前体积，清理后按需重建。

手感修复

拖拽表头列宽不再误触发换列；频谱叠加层不再继承底层 DIM/BOLD，柱子干净不闪。

08 / FAQ

常见问题。

支持哪些音源？

酷我、酷狗、QQ、网易云、咪咕、哔哩哔哩、千千、JOOX、5sing、Jamendo、Apple Music、汽水与本地音乐；同时支持 lx-music 兼容的 JS 自定义音源，可在设置里调整优先级。

运行需要装什么？

播放依赖 libmpv。Linux 用发行版的 libmpv 包，macOS 用 brew install mpv，Windows 直接下载 Releases 里已打包 libmpv 的版本。频谱可视化在 Linux 额外需要 pw-record（PipeWire）或 parec（pulseaudio-utils）。

怎么开启频谱可视化？

按 w 即可，状态会写入 [ui] visualizer；也可以设 visualizer = "bars" 默认开启。画的是系统输出监视流，所以 voicefox 自己不出声时柱子是平的。

终端画不出封面怎么办？

封面协议支持 Kitty / Sixel / iTerm2，识别不出时回退 Unicode 半格。可在 [ui] cover_protocol 里显式指定，避免自动探测误判。

数据存在哪？怎么备份？

配置与会话使用平台配置目录，缓存使用缓存目录。提供 --export-data / --import-data 做整库备份与迁移，导入时会先自动备份原数据。

开源协议是什么？

MIT License，源码在 GitHub：emoeem/voicefox。
