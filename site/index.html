VoiceFox 是一个键盘优先的终端音乐播放器：聚合多音源、歌词、本地音乐、下载、收藏、历史与歌单，让完整的音乐工作流留在你的 TUI 里。

01 / Features

一个播放器，完整的音乐工作流。

稳定的 TUI 发布线持续打磨，同时保留 Flutter + Rust 的新架构实验线。

01 / SEARCH

多音源聚合

跨音源搜索、失败换源、歌手/专辑、歌单、分类与排行榜。

02 / PLAYER

libmpv 播放

ReplayGain、EQ、A-B 循环、淡入淡出与键盘/鼠标队列管理。

03 / LYRICS

歌词体验

LRC / KRC / QRC / YRC，支持翻译、罗马音与全屏歌词。

04 / LOCAL

本地音乐库

扫描、标签、封面、歌词、CUE 分轨与文件诊断。

05 / DOWNLOAD

下载与整理

并发分片、完整性校验，以及标签、封面、LRC 写入。

06 / DESKTOP

桌面集成

Linux D-Bus / MPRIS、Windows 通知，以及 Kitty / Sixel / iTerm2 封面。

02 / Workflow

从发现歌曲到整理本地库。

搜索、播放、下载和本地管理保持同一套交互。

01 / DISCOVER搜索与换源跨音源检索，结果不理想时直接切换来源。
02 / PLAY加入队列播放、收藏、歌手/专辑详情保持键盘路径。
03 / SAVE下载与歌词并发下载并写入标签、封面与歌词。
04 / LIBRARY回到本地扫描、CUE 分轨、筛选、排序和诊断。

05 / Get Started

三行命令，开始使用。

Linux / macOS 可以直接从源码构建；Windows 用户可使用 Releases 中已经打包好 libmpv 的版本。

git clone https://github.com/emoeem/voicefox.git
cd voicefox
cargo build --release
