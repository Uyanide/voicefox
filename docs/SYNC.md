# VoiceFox 同步说明

VoiceFox 的跨音源同步使用独立的同步层，不把同步逻辑塞进具体音源实现。

## 当前架构

```
UI / SyncOverlay
    ↓
app::sync
    ↓
lx-core::sync::SyncEngine
    ├── matcher
    ├── SyncPlan / Diff
    └── execute
    ↓
lx-source::sync::SyncProvider
    ├── 网易云音乐
    └── QQ 音乐
```

新增音源时，原则上只需要实现 `SyncProvider`，匹配器和核心执行逻辑保持不变。

## 匹配优先级

1. ISRC
2. 同平台歌曲 ID
3. 标题 + 歌手 + 专辑精确元数据
4. 标题/歌手元数据 + 时长
5. 模糊元数据匹配
6. 无法匹配

默认时长容差为 5 秒，模糊匹配阈值为 92。
## 同步策略

当前同步默认采用**双向、增量、非镜像**策略：

- 本地歌单存在而远端没有：创建远端歌单并上传本地歌曲。
- 远端歌单存在而本地没有：创建本地歌单并拉取远端歌曲。
- 两边都有：生成 Diff，只补充缺失歌曲。
- 默认不会因为一侧缺少歌曲而删除另一侧歌曲。
- “我喜欢”作为独立的收藏集合处理。
- 本地与远端歌单会持久化保存映射，优先按映射 ID，其次按名称匹配。

同步预览会统计上传、下载、已匹配和未匹配数量，并保留未匹配歌曲名称/歌手用于人工处理。

## 当前音源

| 音源 | 登录 | 预览 Diff | 拉取 | 推送 | 收藏同步 |
|---|---|---|---|---|---|
| 网易云音乐 | 扫码 | ✓ | ✓ | ✓ | ✓ |
| QQ 音乐 | 扫码 | ✓ | ✓ | ✓* | ✓* |

`*` QQ 音乐写入接口使用现有平台接口实现，真实账号下仍需要继续做端到端验证。
## 网易云登录注意事项

网易云扫码登录已经加入：

- 二维码生成与轮询；
- 登录成功后的 Cookie 收集；
- 已有登录会话刷新；
- 风控/验证状态识别；
- 登录会话失效后的错误传播。

但是，**“代码层登录流程通过测试”不等于网易云官方风控一定允许扫码登录**。

实际测试中，如果手机网易云显示：

> 检测到当前设备环境异常，本次操作已拦截

这表示网易云服务端拒绝了当前登录环境。它不是 VoiceFox TUI 渲染错误，也不能通过单纯增加轮询重试解决。

遇到这种情况：

1. 不要连续重复扫码；
2. 等待网易云风控限制解除后再测试；
3. 可先用官方网易云客户端/网页确认账号本身正常；
4. 再使用 VoiceFox 做单次扫码验证；
5. 如果仍然被拦截，需要继续调整网易云登录请求的客户端环境，而不是把它标记为“登录成功”。

## 验证

同步核心目前有匹配器单元测试，覆盖：

- 同平台 ID 优先；
- 跨平台精确元数据匹配；
- 明确识别未匹配歌曲。

网易云二维码状态映射也有单元测试。

真实账号的扫码登录、远端歌单写入和收藏写入属于网络端到端测试，不能由离线单元测试替代。
## 数据安全与同步原则

同步不会把账号密码写入同步数据。

平台登录态仍由各音源自己的会话存储管理。同步映射只记录本地歌单与远端歌单之间的关联，不保存远端账号密码。

在执行同步前，建议先查看 Diff；对无法匹配的歌曲，不会强行用低置信度结果替换。

## 后续工作

当前同步层已经具备扩展到更多音乐平台的基础。后续重点包括：

- 设置页提供稳定、可见的“账号与同步”入口；
- 完善歌单级 Diff 明细和确认流程；
- 更完整的未匹配处理；
- 登录刷新与失效后的重新登录提示；
- QQ 音乐真实账号端到端验证；
- 更多音源的 `SyncProvider` 实现。
