# VoiceFox 0.4.0

## 版本概览

这一版的主角是**封面主色跟随**：界面强调色会从当前专辑封面里取主色并柔和混入，
换歌即换氛围。因为这改变了既有默认外观，版本号走到 **0.4.0**（不需要迁移，
关掉这一个开关就回到原来的观感）。

此外有四组打磨：**交互一致性**（音量键、翻页步长、双击、底栏滚轮、键盘 seek）、
**外观细节**（加载态进度条、通知堆叠、空态引导、卡拉OK 歌词折行、窄终端兜底）、
**键位提示真实化**（提示改成读你实际配置的绑定），以及**网易云音源的内部收敛**
（统一请求指纹 + 登录失效判定）。

---

## 一、封面主色跟随强调色（新功能）

播放时从当前封面提取主色，柔和混入界面强调色 —— 选中行、边框高亮、进度条、
状态栏强调等所有走 `accent` 的地方一起变，换歌即换色。

- **提取方式**：在封面解码线程里顺手做（复用已经解码好的 ≤640px 图像），
  缩到 64×64 → 转 Oklch → 按"色度 + 占比"加权选出主色；接近黑/白/灰的像素不参与投票，
  因此**灰调封面提取不出颜色时自动回落主题 accent**（不会给出脏色）。
- **归一化**：深色封面的主色原本偏暗，混进深色主题几乎看不出、还会把选中行文字压得读不清；
  发布前会把明度/色度夹到"鲜艳但不过曝"的区间，深色封面自动提亮。
- **柔和混合**：不是硬替换主题色，而是按档位与主题 accent 混合。
- **防串歌**：结果按封面路径匹配，提取完成前切了歌不会把旧颜色套到新封面上。

配置（`[ui]`）：

```toml
accent_follow_cover = "strong"   # off / subtle / strong（true = strong，false = off）
```

设置页「界面 → 封面主色跟随」可直接循环切换。**不想要就设 `off`**，观感与 0.3.x 完全一致。

## 二、交互一致性

- **音量键在所有页签可用**：`Ctrl+↑/↓` 原先只在队列页生效，现在与 `.` / `,` 的全局音量行为对齐
  （输入状态下仍然让位给文本编辑）。
- **翻页步长可配置**：新增 `ui.page_step`（默认 10），`PgUp/PgDn` 的步长不再各处硬编码
  （队列/搜索/历史/排行榜/歌单/详情/下载/帮助统一读它；滚轮仍用 `scroll_amount`）。
  设置页「界面 → 翻页步长」可循环 5/10/15/20。
- **底栏滚轮调音量**：悬停在底栏**任意**段滚动都可调音量（原先只有音量段且依赖过期的悬停缓存）。
- **双击判定放宽到 2px 邻域**：手抖也能触发双击，不再要求像素级精准。
- **键盘 seek 覆盖到常用页**：`←/→` 快退/快进在队列、历史、本地音乐页都可用
  （搜索/排行榜/歌单/收藏/设置页的 `←/→` 另有用途，保持不变）。
- **设置页状态消息自动消失**：不再永久占住最后一行。

## 三、外观细节

- **加载态进度条**：时长未知且处于 Loading 时，画一个来回移动的色块（相位由时间量化，
  无状态、无额外重绘）。
- **通知堆叠**：同时最多显示最近 3 条通知（自下而上），操作按钮只在最新一条上渲染，
  避免命中打架。
- **空态引导**：队列为空时提示"在 搜索(2) · 排行榜(3) · 歌单(4) 页按 Enter 播放，歌曲会自动加入队列"；
  有筛选词而结果为空时提示按 Esc 清除。
- **卡拉OK 歌词折行**：逐字高亮的歌词行与普通行一致地交给 `Paragraph` 折行，
  逐词样式跨行保留，不再被截断。
- **窄终端兜底**：窗口小于 60×20 时整屏显示"窗口太小，请调整终端尺寸"，并清空鼠标命中区
  （防止点到过期坐标）。

## 四、键位提示真实化

界面里写死的快捷键提示（状态栏排序、本地页标题、右键菜单里的 `Ctrl+O` / `Space` / `b` / `n` / `.` / `,` 等）
改为读取**你实际的绑定**：

- 新增 `KeybindingConfig::key_hint(page, action)`，页面级优先、全局兜底，与按键分发同序；
- 你把某个动作改成别的键（或删掉绑定）之后，提示会跟着变或整段省略，不会再指着一个按不出效果的键。

## 五、网易云音源内部收敛

- **统一请求指纹**：登录、eapi、带 cookie 的公开 GET 原先各用一套 UA/Referer
  （桌面客户端 / 浏览器 / 默认 `voicefox/0.1`）。带着同一份 `MUSIC_U` 反复换指纹对风控不友好，
  现在整个 `wy` 模块统一成桌面客户端 UA + `music.163.com` Referer。
- **eapi 调用收敛成一个实现**：歌词、歌单、搜索、取流地址原先各自复制一份加密 POST，
  现在统一走 `eapi_post`，业务码由调用方判定。
- **登录失效可识别**：接口返回"需要登录"的业务码（weapi `301` / eapi `512`）时不再当成
  "没有数据"，而是明确提示 —— 已登录会提示"登录已失效，请重新扫码登录"，未登录提示"请先在设置页登录网易云"。

## 六、兼容性

- **配置与数据无需迁移**，新配置项都有默认值。
- **默认外观有变化**：`accent_follow_cover` 默认 `strong`。想保持 0.3.x 观感请设成 `off`。
- 旧写法 `accent_follow_cover = true / false` 仍然接受（`true` = `strong`，`false` = `off`）。
- 新增依赖 `palette 0.7`（本就已在依赖树里，编译成本可忽略）用于 Oklch 色彩处理。

## 升级提示

直接替换二进制。想让界面跟着封面变色，什么都不用做；想固定主题色，把
`[ui] accent_follow_cover` 设为 `off`，或在设置页「界面 → 封面主色跟随」切到"不跟随"。
