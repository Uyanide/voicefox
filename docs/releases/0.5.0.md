# VoiceFox 0.5.0

## 版本概览

0.4.0 之后的这轮更新把「播放器该有的桌面能力」补齐：**频谱可视化**（`w`）、
**睡眠定时器**（`t`）、**Windows SMTC**（硬件媒体键 / 系统媒体浮层），
并把**歌单互通**从单向导入扩成「导入 + 导出 M3U8 + 推送到网易云」，
网易云歌单改成**只读镜像缓存 + 增量合并**。

同时修掉了两个明显影响手感的问题：**拖拽表头列宽会误触发换列**、
**频谱采集断流后画面冻结**。版本号走到 **0.5.0**（新增用户可见功能）。

---

## 一、频谱可视化（新，`w`）

在内容区叠加 cava 风格的柱状频谱，采集的是**系统输出监视流**（和 cava 同口径），
因此画的是电脑正在出声的混音，voicefox 自己不出声时柱子是平的。

- **开关与落盘**：`w` 运行时开关，状态写入 `[ui] visualizer = "off" / "bars"`；
  `visualizer_style` 可选 `classic`（默认，cava 风格）/ `modern`（更紧凑）。
- **采集**：Linux 优先 `pw-record --target @DEFAULT_MONITOR@`，没有则回退
  `parec <sink>.monitor`；两者都输出 s16le / 44.1kHz / 双声道裸 PCM。
  采集与分析都在专属线程，主循环每帧只读一份 96 个 f32 的快照。
- **分析**：Hann 窗 + 4096 点 FFT → 50Hz–12kHz 对数频带 → dB 归一化 →
  monstercat 式相邻平滑 → 攻击快/衰减慢的时间平滑 + 慢速下落的峰顶标记 +
  慢释放自动增益。
- **渲染**：主题色纵向渐变、峰顶高光小帽；由 `realfft` 负责 FFT、`colorgrad` 负责插值。
- **健壮性**：采集子进程退出（切换输出设备、PipeWire 重启）时会**自动重连**；
  超过 1s 没有新帧就不再画旧帧，避免出现「一屏永远不动的柱子」。
- **叠加层不抢模态**：扫码登录、同步浮层、本地诊断打开时频谱让路，不会把模态糊掉。

依赖：新增 `realfft`、`colorgrad`。

## 二、睡眠定时器（新，`t`）

- 全局 `t` 打开菜单，可选 15 / 30 / 45 / 60 / 90 / 120 分钟，或「关闭」。
- 到点后在最长 10s 的窗口内**淡出**再暂停，复用 libmpv 引擎自带的音量淡出，
  不额外开线程；恢复播放时音量会还原。
- 启用后底栏出现倒计时段（点击该段同样打开菜单）。

## 三、Windows SMTC 与媒体控制

- **Windows SMTC**：接入 System Media Transport Controls —— 硬件媒体键、
  系统媒体浮层、蓝牙耳机按键可控制播放 / 暂停 / 切歌 / 进度，系统浮层同步显示
  封面与歌名。`[integration] smtc = false` 可关闭（默认开）。
  实现上在专属线程创建隐藏窗口并泵消息，通过 `souvlaki` 对接。
- **媒体控制层重构**：把原先散在 `main.rs` / `mpris.rs` 的媒体控件胶水抽成
  `media_controls`（平台无关的执行与快照）与 `media_session`（共享数据层），
  Linux MPRIS 与 Windows SMTC 只做协议翻译，主循环接入点收敛成一套。

## 四、歌单互通与跨端推送

- **导出 M3U8**：歌单页「自建歌单」范围按 `Shift+E`，预填音乐目录路径（可编辑）。
  本地歌曲写绝对路径，在线歌曲写 `voicefox:<source>:<id>` 标识行 ——
  其他播放器 / 车机可直接打开本地部分。
- **导入**：`--import-playlist` 或设置页「导入外部歌单」，支持
  M3U / M3U8、LX Music JSON、网易云歌单 JSON。
- **推送网易云（只追加）**：歌单页「自建歌单」`Shift+P` 推送选中歌单，
  收藏页 `Shift+P` 推送全部收藏到「我喜欢」。
  流程为：登录预检 → 选择远端目标（或按本地名新建）→ 五级匹配生成追加 Diff →
  确认后分批执行，显示进度、可 `Esc` 取消。**只追加、不删除**远端已有歌曲；
  无法匹配的会逐首列出原因，不会强行写入。

## 五、网易云歌单改为只读镜像 + 增量合并

网易云歌单不再复制成本地歌单，而是把远端歌单连同歌曲元数据缓存在**远程集合缓存**里，
播放时仍走现有网易云地址解析。缓存**跨进程落盘**，重启后「我的歌单 / 收藏」
不会悄悄退回热门歌单或变空。远端拉取出现局部失败时只按 id **增量合并**，
不会整体替换 —— 一次频控不会把已缓存歌单清空。

## 六、缓存管理（设置页）

设置页（全局 `8`）→「数据与本地库」分类底部新增两行，值列显示当前体积：

- **清除封面缓存**（Linux 为 `~/.cache/voicefox/covers`），清理后按需重新下载。
- **清除网易云歌单缓存**，删除歌单镜像，下次同步自动重建。

体积只在进入该分类或执行清理时统计一次，不每帧扫盘。

## 七、本地音乐「播放」列

本地音乐页默认把「时长」和「音质」合并成一列「播放」（`时长 · 音质`），
减少一列占用；其它页面列配置不变。

## 八、问题修复

- **拖拽表头列宽会误触发换列**（本次重点）：列边界的命中改用**表头实际宽度**，
  不再用整块内容区宽度。主页面宽布局下队列只占右栏，两者宽度不同，旧逻辑会把
  「拖边界改宽」判成「拖表头换列」，表现为相邻列互相卡顿。
- **频谱断流后冻结**：采集子进程退出后自动重连（见第一节）。
- **频谱继承底层修饰色**：叠加层显式清除底层内容的 `DIM`/`BOLD`，
  柱子不再忽明忽暗，也少掉大量无谓的 SGR 切换。
- **淡化与暂停互相打断**：暂停会结束进行中的淡出并还原实际音量，
  避免「淡出到一半暂停、恢复播放没声音」。

## 九、兼容性与升级

- 配置与数据**无需迁移**，所有新配置项都有默认值：
  `[ui] visualizer` / `visualizer_style`、`[integration] smtc`。
- Windows 用户升级后 SMTC 默认开启；不需要可设 `[integration] smtc = false`。
- 频谱需要 Linux 上的 `pw-record`（PipeWire）或 `parec`（pulseaudio-utils），
  缺少时会给出明确提示而不是静默失败。

## 升级提示

直接替换二进制即可。想默认开着频谱就把 `[ui] visualizer` 设为 `"bars"`，
或在界面里按一次 `w`；睡眠定时器按 `t` 打开。
