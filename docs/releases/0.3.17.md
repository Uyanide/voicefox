# VoiceFox 0.3.17

## 版本概览

本次更新主要围绕鼠标交互、界面命中区域、二维码登录稳定性以及登录会话管理进行完善。

同时优化了拖动调整布局时的 Preview 行为：鼠标移动后立即更新 Preview，松开鼠标后再提交最终布局，使拖动过程更加跟手，同时保持布局状态的确定性。

## 鼠标交互与界面修复

- 修复渲染区域与鼠标点击区域不一致的问题。
- 修复不同终端显示宽度的 Source Tab 点击区域，正确处理中文等 CJK 字符。
- 统一多个列表页面的行命中测试逻辑。
- 修复 Settings 页面鼠标点击区域，使其与实际渲染的两列布局保持一致。
- 修复 Queue、Playlist、History、Favorites、Leaderboard 等页面在边框、标题行和滚动状态下的鼠标定位问题。
- 新增共享的列表行命中测试组件，减少各页面重复的坐标计算。
- 新增 CJK Source Tab 宽度以及列表行边界相关回归测试。

## Resize Preview

- 鼠标拖动分隔线时立即更新 Preview。
- Preview 与当前鼠标位置保持同步，不再需要等待 MouseUp 才看到布局变化。
- MouseUp 时提交最终布局状态。
- 保持 Preview 与最终布局使用一致的坐标逻辑。
- 本版本暂不加入基于时间的插值、Spring 或其他动画效果，避免终端字符网格下产生视觉延迟或 Preview 与最终布局短暂不一致的问题。

## 二维码登录优化

- 统一二维码登录状态模型，覆盖等待、已扫码、登录成功、二维码过期、登录失败、网络错误、风控、服务器错误和无效会话等状态。
- 增加二维码轮询的临时错误重试机制。
- 使用有界指数退避，避免网络异常时高频轮询导致额外的风控问题。
- 防止同一个二维码会话出现重复轮询。
- 临时网络错误发生时继续保留有效二维码，不再直接丢失当前登录会话。
- 优化网易云音乐二维码登录，切换到 EAPI 二维码接口并正确维护登录所需的 Session Cookie。
- 修复酷狗二维码登录轮询过程中 Session 状态没有持续复用的问题。
- 完善 QQ 二维码登录回调过程中的 Session 状态保持。
- 完善各音乐源二维码状态码映射并增加对应测试。

## 本次版本重点

本版本没有追求额外的视觉动画，而是优先保证鼠标交互、布局计算和二维码登录状态的正确性与稳定性。

Resize Preview 当前采用“鼠标移动立即预览 + MouseUp 提交”的方式，已经能够提供跟手的终端交互体验。后续如果实际使用中发现快速移动鼠标时仍存在明显的跳格感，再考虑加入轻量级视觉插值层。
