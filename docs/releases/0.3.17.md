# VoiceFox 0.3.17

## Release overview

This release focuses on input correctness, mouse interaction, QR login reliability, and source-session handling. It also makes the resize Preview interaction more consistent: the Preview updates immediately while dragging, and the final layout is committed on mouse release.

## UI and mouse interaction

- Fixed mouse hit-testing so rendered regions and clickable regions use the same geometry.
- Corrected source-tab hit areas when labels have different terminal display widths, including CJK text.
- Unified list-row hit testing for several list-based pages.
- Fixed Settings panel mouse targeting so clicks align with the rendered two-column layout.
- Fixed queue, playlist, history, favorites, and leaderboard row hit-testing around borders, headers, and scrolling.
- Added regression tests for shared row geometry and CJK source-tab widths.
- Resize Preview now updates immediately during mouse movement and commits the final layout on MouseUp.

## QR login

- Added a shared QR login status model covering waiting, scanned, success, expired, failed, transient network/risk-control/server errors, and invalid sessions.
- Added transient QR polling retry with bounded exponential backoff instead of immediately discarding the QR session.
- Prevented duplicate polling while a QR request is still in flight.
- Kept valid QR previews visible while transient errors are retried.
- Improved NetEase QR login by using the EAPI QR endpoints and preserving the required session cookies.
- Hardened KuGou pending QR sessions so the same device/session state is reused during polling.
- Preserved QQ QR login session state during its callback flow.
- Added QR status mapping and regression coverage across the affected sources.

## Validation

The release candidate was verified with:

- cargo fmt --all -- --check
- cargo check --workspace
- cargo test -p lx-core -p lx-source -p voicefox-app --no-fail-fast
- git diff --check

Test results: **30 core tests passed, 170 source tests passed, 4 JS API integration tests passed, and 231 application tests passed.** Network-only smoke tests remain ignored by default and require an explicit network run.

## Notes

The resize interaction deliberately does not add time-based visual interpolation or spring animation in this release. The terminal layout remains deterministic while the Preview is directly driven by the latest mouse position.
