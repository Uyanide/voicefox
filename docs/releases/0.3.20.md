# VoiceFox 0.3.20

## 版本概览

这次更新集中在**设置页**和**底部控制栏**这两处日常用得最多、也最容易"找不到、点不动"的地方。

设置页从"67 个设置行 + 86 个快捷键"重做成**分类 + 行光标 + 鼠标一等公民**：左边 7 个分类、
右边选中的分类内容，`↑↓` 选行、`Enter` 执行、`Space` 切开关，**鼠标点哪里就是哪里**。
所有"取值类"设置统一改成**弹出选择菜单**（带 `✓` 当前值），不再需要记住循环键。
设置页自己的字母/功能键从 **45 个精简到 6 个**，并按你的选择保留了分类与导航键。

同时加入**主题系统**（17 套主题，可直接切换）、底部控制栏**拖拽调高**，
以及一个重要的稳定性修复：**封面图片协议误判导致满屏花屏**。

外观本身保持原样：面板仍是四周全框、顶部仍是原来的排版（此前试做的"减少边框 / Now Playing 头部"
已按反馈回退）。

## 一、设置页重做

### 7 大分类 + 行光标

`账号与扫码 / 界面 / 播放 / 音源与歌词 / 通知与集成 / 下载 / 数据与本地库`

- 宽屏（≥100 列）：左侧分类栏（**带边框**）+ 右侧该分类的设置项；窄屏：先选分类、`Enter` 进入、`Esc` 返回。
- `↑`/`↓` 移动行光标（当前行有明显的 `▶` 与选中底色），`Enter` 执行，`Space` 对开关/取值行等同 `Enter`。
- 每一行都在代码里**显式声明**自己属于哪个分类（不再靠下标区间推断），因此以后插入/删除设置项不会串分类。

### 鼠标是一等交互方式

点分类切换、点设置行激活、点开关直接切换、点取值行打开菜单、点内嵌列表条目选中、
点命令行按钮执行、右键移除、拖拽排序 —— 全部与键盘走**同一个激活入口**，
而且**渲染出来的矩形与鼠标命中的矩形来自同一份几何数据**（不存在"画在这里、点在那里"）。

### 原来在下方的 4 个管理面板并进了分类

以前设置页下方固定占着"JS 音源 / 本地目录 / 状态栏字段 / 扫码登录"四个面板，靠 `s` 循环切换，
把垂直空间切走一大块。现在它们各自并入对应分类，**同一时刻只显示当前分类的内容**：

| 原面板 | 现在的位置 |
|---|---|
| JS 音源列表（含 ✓/✗ 与加载失败原因） | 音源与歌词 |
| 状态栏字段（勾选 + 排序） | 界面 |
| 本地音乐目录（添加/移除/重新扫描） | 数据与本地库 |
| 扫码登录（登录状态 / 远程歌单缓存） | 账号与扫码 |

### 分类栏与内容区都能拖拽调整大小

- 宽屏：分类栏与内容之间是**可拖的纵向分界线**（改分类栏宽度）；设置行区与内嵌列表之间是**可拖的横向分界线**（改列表高度）——这正是"上面一大堆、下面一小条"的解法。
- 分界线**独占自己那一格**，不会压住任何内容；拖动实时预览、松开落盘。第一次拖动之后，内嵌列表就会按你的比例给足高度并永久记住。

### 快捷键精简

设置页现在只保留：`←/→`（分类）、`↑/↓`（行光标/列表光标）、`Enter`、`Space`、`Esc`、输入模式的文本编辑键，
以及 `p`（循环主题）、`P`（账号与扫码）、`Shift+P`（封面协议循环）。
**删掉了 39 个字母键与 18 个功能键绑定**，不会再出现"按错键触发了别的设置"。

例外保留了 4 个内嵌列表操作键：`a`（添加）/`d`（移除）/`h`（检测）/`r`（重新扫描），
且**只在对应列表获得焦点时生效**（鼠标点命令行按钮同样可用）。

## 二、取值类设置全部改为选择菜单

以下设置点击/回车即弹出带 `✓` 当前值的菜单，选择后立即生效并写入配置，**不需要记住循环键**：

主题、播放音质、播放模式、默认音源、解析策略（含「目标平台」子菜单）、均衡器预设、
状态栏字段（每项独立勾选）、音源开关（哪些在线音源参与搜索）、歌词偏移。

顺带升级：**音源开关**从"`y` 选一个 + `K` 切"改成逐项 `✓` 的菜单，**歌词偏移**从 `[`/`]` 改成档位菜单（含负值，双向一步可达）。

## 三、主题系统（17 套）

接入 `ratatui-themes`，在**保持 Ratatui 与现有观感**的前提下支持整界面换肤：

- 内置 **17 套**：`Voicefox`（默认，沿用手工调好的 Catppuccin 槽位，观感与历史版本完全一致）+ 主题库 16 套（Dracula / Nord / Tokyo Night / Catppuccin Mocha·Latte / Gruvbox / Solarized / Monokai Pro / Rosé Pine / Kanagawa / Everforest / Cyberpunk / Midnight Commander …）。
- 切换位置：设置页 → **界面** 分类的第一行「界面主题」（值显示 `当前主题 ›`，点击或 `Enter` 打开菜单），
  或在设置页按 **`p`** 直接循环。
- 选中即整界面换肤并落盘，无需重启。主题库只提供 10 个语义色，项目的 surface/overlay 等层次色由
  `bg → fg` 插值推导、色相槽位折叠到对应语义色，因此**深色与浅色主题都可用**（浅色主题的分层方向会自动反向）。

## 四、底部快速控制栏

- **可拖拽调高**：底栏顶行最右的 `⇕` 把手可以用鼠标上下拖动，行数在 **1–6** 行之间调整（`ui.status_bar_height`），展开后能看到全部信息段。
- 鼠标悬停在音量段上**滚动滚轮即调音量**；音质段显示的是你的**偏好**，实际播出不同时会附注"实播 …"；音源策略（自动 / 优先 X / 只用 X）会直接显示在音源段上，切换后立即对当前歌曲重新解析。

## 五、修复

### 封面花屏（满屏 `?` 字符）

这是本次最重要的稳定性修复。封面图片协议原先用"向终端发查询再读回复"来判定，而这个查询发生在**进入 raw 模式之前**，自己的查询会被终端回显当成回复；再加上 `KITTY_WINDOW_ID`、`TERM_PROGRAM` 这类环境变量会**穿透 tmux / ssh**，于是很容易选中一个终端其实不支持的协议 —— 一旦选错，整幅图片载荷会被终端**当文本打印**出来（实测一个封面就是 227 KB、98.8% 是可打印字符，并且每帧重发，6 秒约 1 MB），表现就是满屏 `?`。

现在：

- `auto` **不再向终端发查询**，只根据环境变量做**正向识别**（`KITTY_WINDOW_ID` / `TERM` / `TERM_PROGRAM`），认不出来就用半格渲染（安全）；
- 检测到 **tmux / screen** 时一律退半格（无法确认是否开启图片透传）；
- 已知**不可能成立**的组合会被纠正：kitty 终端不支持 sixel，若配置写死 `sixel` 会自动改用 kitty 协议并给出告警。

如果你确实需要某种协议，显式写 `ui.cover_protocol = "kitty" | "sixel" | "iterm2" | "halfblocks"` 即可（显式配置优先）。

### 其它修复

- **分割条不再压住面板最后一行/列**：给分界线留出独立 1 格 gutter，"滚到底最后一行看不见/点不到"的问题消失；顺带修掉排行榜窄屏在特定行数下的 panic。
- **QQ 音乐搜索**：HTTP 非 2xx 与空响应体不再被当作"搜到 0 条"，会给出明确错误。
- **网易云外链**：返回 200 但实际是错误页面的"假成功"URL 不再被当成可播放地址。
- **JS 音源**：加载失败会在界面与状态栏明确显示名称、来源与失败原因（不再静默）。
- **换源重试语义**：本地文件歌曲不再被误判成"需要换源"。
- **均衡器预设**：频段与标签收敛到唯一来源，不会再出现两处定义漂移。

## 六、兼容性与已知取舍

- `[keybindings.pages.settings]` 里的 `settings_*` 键位**仍被配置系统接受**（兼容既有配置文件与公共 API），但设置页不再拦截它们，所以不会再在设置页触发动作；v9 配置迁移会清理因此变成死键的旧绑定。
- 主题默认仍是 `Voicefox`；`[theme]` 里那套十六进制槽位只在默认主题下生效，主题库主题的配色由主题自己决定。
- 新装配置下，内嵌列表初始按"够用就好"给高度；**第一次拖动分界线之后**即按比例给足并持久化。
- 设置页的 `a/d/h/r` 四个列表操作键是刻意保留的例外（见上）。

## 升级提示

设置页 → `界面` → 第一行「界面主题」（或按 `p`）。
